# =============================================================================
# 🎯 THE UNIFIED PIPELINE
# =============================================================================

INPUT IMAGE (PNG/JPG)
    ↓
    ├─→ [Segmentation] UNet Model
    │    ├─ Produces: Binary mask
    │    └─ Outputs: Tumor area %, Segmentation confidence
    ↓
    ├─→ [Classification] Ensemble of:
    │    ├─ DenseNet121
    │    ├─ EfficientNet-V2-S
    │    └─ (Optional: More models)
    │
    │    Outputs:
    │    ├─ Disease Probability (0.0-1.0)
    │    ├─ Classification logits
    │    └─ Per-class probabilities
    ↓
OUTPUT: PredictionResult
    ├─ Segmentation Mask (array)
    ├─ Tumor Area % (float)
    ├─ Disease Probability (float) ← PRIMARY METRIC
    ├─ Predicted Class (0/1)
    ├─ Logits & Probabilities
    └─ Ensemble weights & metadata


# =============================================================================
# 🚀 USAGE EXAMPLES
# =============================================================================

1️⃣  SIMPLEST: 3 Lines of Code
────────────────────────────────────────────────────────────────────────────
from unified_predictor import PancreScanPredictor

predictor = PancreScanPredictor()
result = predictor.predict("image.png")
print(f"Disease: {result.disease_probability:.2%}")


2️⃣  WITH CONFIG: Use Preset Configurations
────────────────────────────────────────────────────────────────────────────
from config import get_gpu_config
from unified_predictor import PancreScanPredictor

config = get_gpu_config()
predictor = PancreScanPredictor(
    seg_model_path=config.seg_model_path,
    classifier_names=config.classifier_names,
    classifier_paths=config.classifier_paths,
    ensemble_weights=config.ensemble_weights,
    device=config.device
)
result = predictor.predict("image.png")


3️⃣  BATCH PROCESSING: Multiple Images
────────────────────────────────────────────────────────────────────────────
predictor = PancreScanPredictor()
results = predictor.predict_batch("image_directory/")

for i, result in enumerate(results):
    status = "DISEASE" if result.predicted_class == 1 else "NORMAL"
    print(f"{i+1}. {status}: {result.disease_probability:.2%}")


4️⃣  COMMAND LINE: No Python Code
────────────────────────────────────────────────────────────────────────────
python unified_predictor.py --image data/images/sample.png --visualize
python unified_predictor.py --image-dir data/images/


5️⃣  CUSTOM ENSEMBLE: Mix Your Own Models
────────────────────────────────────────────────────────────────────────────
predictor = PancreScanPredictor(
    classifier_names=["densenet121", "convnext_tiny", "resnet50"],
    classifier_paths=["model1.pt", "model2.pt", "model3.pt"],
    ensemble_weights=[0.5, 0.3, 0.2]
)

# 🔄 HOW IT INTEGRATES WITH EXISTING CODE

TRAINING WORKFLOW:
──────────────────────────────────────────────────────────────────────────
1. Train classification models:
   python PancreScan/train_ensemble_smart.py
   → Saves: PancreScan/outputs/densenet121_best.pt

2. Validate with k-fold:
   python PancreScan/run_kfold_cv.py
   → Saves: PancreScan/outputs/kfold_*/

3. Use in unified predictor (NO CODE CHANGES):
   predictor = PancreScanPredictor(
       classifier_paths=["PancreScan/outputs/densenet121_best.pt"]
   )

PREDICTION WORKFLOW:
──────────────────────────────────────────────────────────────────────────
Before: predict.py (segmentation only)
        ↓ manual ↓ classify.py (classification only)

After:  unified_predictor.py (integrated end-to-end)
        ↓ one call ↓ result with everything
